# Python 3.14

A Debian repository for the official CPython 3.14 framework, built for arm64 devices running iOS 14.5 or later.

Add the source URL to Sileo, Zebra, or Cydia:

`https://k1tty-xz.github.io/`

The package is built in [python-ios-arm64](https://github.com/k1tty-xz/python-ios-arm64) and follows CPython's official iOS framework model. It is not a standalone command-line or pip distribution.
