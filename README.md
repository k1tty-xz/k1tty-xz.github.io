# k1tty-xz iOS Repository

A Debian repository for CPython 3.14 on jailbroken iOS arm64 devices.

Add the source in Sileo, Zebra, or Cydia:

`https://k1tty-xz.github.io/`

The package is built in [python-ios-arm64](https://github.com/k1tty-xz/python-ios-arm64). Use the **Sync CPython package feed** workflow to publish the latest successful build and regenerate repository metadata.
